I'm **Shuai Guan** — co-founder & CEO of **[Thunderbit](https://thunderbit.com)**, an AI web scraper that turns any website, PDF, or image into clean, structured data in a couple of clicks. After close to a decade in tech and SaaS, I now spend my time turning capable AI models into practical, **no-code tools** — so anyone, not just engineers, can use the web's data at scale. Michigan engineer, based in the **San Francisco Bay Area**, photographer on the side.

---

### ⚡ What I'm building

**[Thunderbit](https://thunderbit.com)** — an AI web scraper for everyone, also open to developers.

| Surface | What it does |
| :-- | :-- |
| **Distill** | Any web page, PDF, or image → clean **Markdown** |
| **Extract** | Structured **JSON / CSV** straight from a schema |
| **Web Data API · MCP server · CLI** | The same engine, wired into your code and AI agents |

> Trusted by teams at Harvard, MIT, BCG, Accenture, Grammarly, Adidas & Puma.

Product at **Jet.com → Walmart** and **Automation Anywhere**, product lead at **Horizon Robotics**, engineering at the **University of Michigan**. A decade of shipping software before turning to AI tooling full-time.
